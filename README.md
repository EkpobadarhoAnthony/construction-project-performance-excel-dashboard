# Construction Project Performance & Executive Dashboard

## 📊 Project Overview

This project is an advanced Microsoft Excel dashboard designed to analyse the financial and operational performance of construction projects.

The dashboard provides management-level insights into:

- Project revenue
- Actual construction costs
- Project profitability
- Budget variance
- Progress performance
- Regional performance
- Client ratings
- Labour and material costs
- Project cost overruns

The project uses a simulated construction-company dataset based on projects across different regions of Nigeria.

---

## 🎯 Project Objectives

The main objectives of this project are to:

- Analyse project revenue and costs
- Identify profitable and underperforming projects
- Monitor projects against their budgets
- Analyse project progress
- Identify cost overruns
- Compare regional performance
- Analyse the relationship between project costs and revenue
- Present construction project information through professional Excel visualisations

## 📈 Key Visualisations

The project contains several advanced Excel charts, including:

### Revenue Analysis
Shows revenue generated by each construction project.

### Profit Analysis
Compares project profitability across the portfolio.

### Revenue to Profit Waterfall
Shows how total revenue is reduced by actual project costs to arrive at total profit.

### Scatter Analysis
Examines relationships such as:

- Staff vs Revenue
- Actual Cost vs Profit

### Bubble Chart
Compares:

- Actual Cost
- Revenue
- Staff Size

### Regional Heatmap
Compares regional:

- Revenue
- Profit
- Profit Margin
- Client Rating

### Histogram
Shows the distribution of project profits.
